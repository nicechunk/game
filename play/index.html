Chain gatewayRPC decides how the browser reaches Solana

NiceChunk uses RPC endpoints to read accounts, refresh world state, and submit signed transactions.

ReliabilityA dedicated endpoint avoids public congestion

A Helius Free plan is normally sufficient for testing and gives this browser an independent request allowance.

Cost boundaryThe key is not a payment to NiceChunk

The API key is stored locally in your browser and used only to build your RPC URL.

SecurityRPC cannot spend SOL by itself

Transactions still require a wallet signature. NiceChunk never sends the saved credential to its own server.

Current connection Shared public Devnet RPC
Create a Helius account, select Solana Devnet, then paste only the API key. The free plan is normally enough for game testing.
Only HTTPS endpoints are accepted. NiceChunk tests the Solana genesis hash before saving to prevent a mainnet or testnet mismatch.
The public endpoint is shared and can be rate limited. It is available as a fallback, not the recommended long-term setting.
Mining Session

Set mining session SOL

Mining uses integer world coordinates and chunk PDA deltas. This amount is a client-side top-up target for a separate plugin-wallet session key. It is not escrow, a transaction spending cap, or an authorization limit. Local Game Wallet mode uses the Game Wallet balance directly.

  • Rendering never decides resource ownership or mining legality.
  • Only integer coordinate proof data is prepared for chain verification.
  • Pending deltas can be confirmed or rolled back without changing base world data.
